# 篡改挑战 · Try to fool the auditor

> **这是一条真实的 AgentState 审计链：14 条记录，其中 3 条是当场拦截的危险操作。**
> 规则很简单——**想怎么改就怎么改，骗过验证器，就算你赢。**

## 开始攻击（一条命令，攻击台全程中文引导）

```bash
python attack.py
```

攻击台会先给你看**可读版审计链**（每条记录一行摘要），然后菜单任选：

```
  1  改一个字符   （选一条记录，隐蔽修改）
  2  删掉一整行   （看它能不能发现少了记录）
  3  插入伪造记录 （JSON 都帮你造好——但链对不上）
  4  大师模式     （用记事本自己改——改完按 5 审判）
  5  审判！       （跑独立验证器，当场宣判）
```

每次攻击后选 5，验证器**当场宣判**，指出你在哪一行动了什么。

## 三种攻法的实测结果（我们替你试过了）

| 攻法 | 结果 |
|---|---|
| 改一个字符（同长度隐蔽修改） | **当场抓获** — 指出行号 |
| 删掉一整行 | **当场抓获** — 链断裂 |
| 插入伪造记录 | **当场抓获** — 链断裂 |

## 为什么改不动

每条记录的 `hash = sha256(前一条的完整 hash + 本条内容的规范化 JSON)`。
改任何一个字符 → 本条 hash 对不上；重算本条 → 与下一条的 `prev` 对不上；
全链重算 → 末行与链外日锚（`day_manifest.json`）对不上。
**要无声无息改一条记录，你必须伪造从那条到今天的整条链 + 链外锚。**
