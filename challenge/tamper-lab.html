下面是一条真实的 AgentState 审计链（14 条记录，3 条是当场拦截的危险操作）。
规则：**用任何方式改掉任何内容，骗过验证器，就算你赢。** 全程在你的浏览器里完成，不上传任何东西。
✅ 链完好 — 还没有任何改动

每条记录的 hash = sha256(前一条完整hash + 本条内容规范化JSON)。

改一个字符 → 本条 hash 对不上；重算本条 → 下一条的 prev 对不上；全链重算 → 末行与链外日锚对不上。要无声无息改一条，你必须伪造从那条到今天的整条链 + 链外锚。

验证逻辑与 verify.py（60 行，仓库公开）完全一致——读懂它，构造任何攻击。

提示：点开卡片 → 编辑 JSON → 点「应用」。改 hash 本身等于伪造身份——链看的是内容。
