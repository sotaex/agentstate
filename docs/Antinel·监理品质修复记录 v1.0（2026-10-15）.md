## 1. 严重（3 项，全修）

### Q-01 ✅ 账本页四个大字与「当天」定义不符 → **大字改当天，累计另起一行**

**改法**（`inbox_server.py::_view_ledger`）：
- 大字取 `led["today"]`（`ledger.summary()` 早就把当日算好了，放在 `tot["today"]`，页面原先没用）；
- 累计值**不丢**：压成一行小字「有记录以来 N 天累计：拦截 … ｜ 注意 … ｜ 防护缺口 … ｜ 已处理/已忽略 …」；
- 加一行口径说明「下列四个数只数**今天**（本地自然日）；有记录以来的累计见本页末行。」

**修前/修后（同一台机器、同一时刻）**：

| 位置 | 修前 | 修后 |
|---|---|---|
| 大字「防护缺口」 | **293**（＝7 天累计） | **0**（＝当天） |
| 同屏顶部灯「失守」 | 0 | 0 |
| 同屏差 | **293 倍** | **0**（口径一致） |
| 累计 | 只此一处 | 保留（71 / 52 / 293 / 88，标注「7 天累计」） |

**判据**：0353 的账本三条（P14 认领位、P14 规格引用、P12 归并）复跑全绿 —— 它只断言页面仍含「拦截危险操作」「防护缺口」等字样与数字对得上，**不钉具体数值口径**，所以口径修正不撞它。

### Q-02 ✅ 日报四卡分母「13」无说明 → **单位补进卡片 ＋ 页头写明「/ N」是什么**

- 卡片分母由「/ 13」→「/ 13 **条**」（单位可见，不只 hover）；
- 页头说明句补一句：「数字后面「/ N」是同一时间窗内的记录条数。」
- ★ **不写「分母」二字** —— 0490 的 U-03 明令正文零「分母」（那是术语词，只在词条口径行定义）。

### Q-03 ✅ 「2 次 / 13」异质单位相除 → **各自带单位、用分号分列**

`inbox_server.py`：`"%d 次</a> / %d"` → `"%d 次</a>；同期记录 %d 条"`。
**连带**：0490 负控 `N-U05` 的**变异锚点同步更新**（否则注入不生效 ⇒ 负控失效 ⇒ U-05 形同没有）。

## 3. 轻度（9 项）＋ 创始人追加（1 项）

### Q-25 ✅（创始人追加）首页「页面上的词都是什么意思（点开看）」→ **整块删除**

三条理由（都可复核）：
1. 它列的 14 个词里 **`Ls` / `granary` / `L0` 三个在页面任何位置都不出现**（脚本逐 key 查 `GL.chip` 落点：均为 0）—— 给页面上没有的东西配定义，正是"说明书摆进界面"；
2. 其余 11 个词**各自都有「？」落点**（筛选条 4 ＋ 级别药丸 3 ＋ 顶部灯 1 ＋ 各处 `GL.chip`）⇒ 同一页两套入口，一屏十几个「？」（Q-11 的双入口问题）；
3. 创始人原话：「根本没必要写，应直接去掉」。

**连带处置（这一条是本轮最曲折的地方，如实记录）**：

| 步骤 | 动作 | 判据反应 |
|---|---|---|
| ① | 删块 | 0353 **P13 红**：`set(GL.TERMS) <= seen` 要求术语表 100% 有落点，`Ls`/`granary`/`L0` 失去唯一落点 |
| ② | 撤这三个词条（裁定为"定义了却点不到"的死角） | 0372 **S09 红**：`TERMS["Ls"]` KeyError —— S09 要它们当**六态词名的比对真源** |
| ③ | **恢复 `Ls`/`L0`**（六态成员，必须留），`granary` 保持撤除 | — |
| ④ | 给 `Ls`/`L0` **真实落点**：运行状态页加一行「灯的六态由重到轻：…」，次序由 `M.PRIORITY` 派生、词名由 `GL`/`M.state_short` 取，只给这两态挂「？」 | 0353 P13 **回绿**；0372 S09 **回绿** |

## 4. 工程／无障碍（3 项，全修）

### Q-20 ✅ `prefers-reduced-motion`（全仓首个）
头部哨标是常驻动效（扫描周期 3.5–12s、涟漪 45–105px），原仓**零处**响应系统偏好。改法：命中 reduce ⇒ **只画一帧静态**、不启动 rAF 循环（色相与形状照旧，状态照样认得出）。

### Q-21 ✅ `ledger.py` 注释与实现同锚

★ 0353 有判据读 `ledger.py` 的**声明区**（「与现有 credits」段到「只负责…记账」段）核对引用指向 —— 本处不在声明区，改它不撞。

### Q-22 ✅ 读数时效补「载入于」
`inbox_model.py::reading_note()` 句尾补「（**载入于 06:32**）」，页面实测显示 ✓。
