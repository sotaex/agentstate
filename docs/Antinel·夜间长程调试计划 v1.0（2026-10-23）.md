## 2. 七条硬规矩（本仓已用事故换来的，夜间不许忘）

1. **前缀逐字**：`TMPDIR=D:/_antmp`（冒号会变成命令名，报 `No such file` 而 rc=0）。
2. **shell 报错 ≠ 进程死了**：日志 0 字节也可能在跑；长任务一律后台 + 任务通知。
3. **判据必须能换掉同一份实现**：每条负控都要打印它抓到的那条问题；只报「N 条全过」＝没执行。
4. **同一事实只许一处实现**：`gaps` 的族界已收归 `facts.harmful_gaps()`；新增规则一律先问「有几处副本」。
5. **期望值禁从实现现状抄**：阈值用比例，汇总数用脚本数；条数 ≠ 件数。
6. **改了产品就要活体回读**：同 URL 重取、字节对比；未回读＝未完成。
7. **提交只 add 自己改的文件**（禁 `-A`）；`--no-verify` 之后必须重签 manifest 并写明哪几条是旧漂移。

## 3. 今晚不做的事（写清楚，免得醒来看见半成品）

- **不删旧词汇**：`STATE_LABEL`（失守/拦截/注意/缺粮/值守中/研发中）整族保留。它是 283 处判据的锚，替换属于后续「旧屏句子迁移」，不是接线。
- **不动 `gap_state` 封闭集、不改 `Item`**：复核期只体现在 `facts` 的派生视图里。
- **不重构 `_p_cases_run` 的 A 线矩阵**：它是回归基线，只加不改。
- **不推送远端、不打 tag**：留给创始人。
