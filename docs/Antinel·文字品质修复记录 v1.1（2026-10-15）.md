## 2. 四处修复

### 2.1 W06：`/ N` 里的 `N` 是裸英文词（★ 这条红是我上一轮自己引入的）

- **红项原文**：`[report] 页面正文露出英文词 'N'（不懂技术的用户看不懂）`
- **来源**：上一轮 Q-02 的连带改动，我给日报页头补了一句口径说明，写作
  「数字后面『/ N』是同一时间窗内的记录条数」。那个 `N` 是我为举例用的**裸英文大写字母**。
- **改法**：

  ```
  改前：数字后面「/ N」是同一时间窗内的记录条数。
  改后：数字后面「/」右边那个数，是同一时间窗内的记录条数。
  ```

- **顺带写进代码注释**：为什么不能写 `/ N`（会撞 W06），以免下一轮又写回去。

### 2.2 W09：`sentinel` 词条里的源码文件名（清单 A-5）

- **红项原文**：`术语 sentinel 的 inc 里出现技术名 '`'：……（这条口径的真源是 `granary.py`）。`
- **为什么是缺陷**：`granary.py` 是**源码文件名**，对用户是纯噪声；把它留在界面等于把内部实现摊开。
- **动手前先查**（这一步是本批的关键，不能凭直觉删）：
  `ci/guard_granary.py` 的 G1–G3 是"合规三铁律"的守门人，是否要求界面上出现该文件名？
  → **实测：G3 只查用词黑名单 `BANNED_IN_TEXT`（如"返利"），从不要求界面出现 `granary.py`。**
  ⇒ **删界面副本不删合规**，真源仍由 `granary.py` ＋ G1–G3 守。
- **改法**：删掉括号里那半句，合规三铁律本身（"不可转让、不可兑换、不承诺收益"）**一字不动**。

### 2.3 冒泡按钮与脚注（清单 B-2 / B-3）

| | 改前 | 改后 |
|---|---|---|
| 主按钮 | 「知道了（去处理）」 | 「**知道了**」 |
| 脚注 | 「不自动消失 · 处理完手工关」 | 「**会一直留着，直到你处理完**」 |

- **B-2 的根据**：代码立场明确是「**确认 ≠ 处理**」（`bubble_ack` 不代用户把事标成已处理，
  否则篡夺用户决定、还把台账改假）。而按钮文案用括号把两件事**绑成一个动作** ⇒ 文案与代码立场相反。
  确认态里「尚未标记处理／处理后请点右上角 × 关闭」已经把后一步说清，不必塞进按钮。
- **B-3 的根据**：「不自动消失」在讲**我们怎么实现的**，用户关心的是"**我不会漏掉它**"；
  「手工关」是口语。改后直接说利益。

### 2.4 `ledger` 词条里的未来承诺（清单 F-4）

- **改前**：「…可以整体导出带走（带走的是这份摘要，不是记录本身）——

## 3. 量具自撞：本轮第 5、6 条

### 第 5 条：启动器生成器把转义字符当普通字符放过

- 写桌面 `.cmd` 时用 JSON 传参，**双反斜杠被还原成单反斜杠**，
  Python 于是把路径里的 `\b`、`a`、`e` 当成**转义控制字符**（退格/BEL/ESC），
  文件里真的写进了这些字符。
- **我的自检只看"非 ASCII 字节数 = 0"**，这几个都是 ASCII ⇒ **自检没拦住**。
- **修法**：生成器改用原生字符串重写；自检增加"控制字符计数 = 0"。

### 第 6 条（★ 最重要）：机器过载会伪造判据红

首轮全量复跑（**且是在改动中途跑的，本身就是混合态**）报出 12 条红。逐条读红项正文后发现：

| 套件 | 红数 | 红项正文自陈 |
|---|---|---|
| `0460` | **9** | 「多半是机器负载让 git 子进程撞了 `VCT_TIMEOUT` ⇒ 本判据**测不出**（量具/环境问题，不是产品缺陷）」 |
| `0490` | 2 | 「夹具失效……本条负控**测不出**，不许报通过；**请重跑**」 |
| `0470` | — | 撞 420 秒超时上限（实测需更久） |
| `0360` | 2 | **真缺陷**（W06/W09） |

⇒ **11 条红里只有 2 条是真的**。

**由此固化两条纪律**：

1. **红项先分类再动手**——「产品缺陷」／「夹具失效（判据自陈『我测不出』）」／「改动前就红」
   三类分开记，**只有第一类进修复批次**。
2. **绝不在全量复跑的中途改产品文件**——混合态那一轮**整体作废**。
   改完再跑，机器空着跑。

> 这条与本项目已有的"量具自撞"纪律同族：**判据会自己说出"我这次测不出"，
> 那是它留给人的一线线索；不读红项正文就动手，等于把量具的噪声当产品缺陷去修。**

且 `0372 S09` 用 `TERMS[k]["w"]` 当六态词名比对真源，改显示名会牵动五个派生面。
