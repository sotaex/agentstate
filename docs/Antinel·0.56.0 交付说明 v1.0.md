## 3 唯一有意后退（代价写在明面上）

**`…/Default/Cookies.txt` 这类带扩展名的副本不再拦。** 旧写法只要路径里出现那个词就拦，所以它也拦；新写法按路径段锚定，`Cookies.txt` 不是那一段。

- 为什么接受：这类副本不是浏览器在用的凭据文件，拦它等于把"备份"当"凭据"；而每条误拦都会消耗你对告警的注意力 —— 一个总在误报的守卫，被关掉只是时间问题。
- 代价：真有 Agent 去读一个手改名的副本，这条规则不响。兜底是别的规则（配置根目录层的 6 条覆盖了真实 profile 位置）。
- 若你不接受这个取舍：改回"名字层再加上扩展名变体"是一条 5 分钟的改动，但它会把误拦从 0 升回个位数。

首轮 31 绿 / 3 红，四条红项全部属**发布态固有的账**，逐条有解、已解、已复跑验证：
