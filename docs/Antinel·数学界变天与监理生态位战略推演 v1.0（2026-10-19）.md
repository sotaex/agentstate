## 1. 第一部分：人机分工资命题——否决权理论

### 1.1 命题与修正

创始人命题：「Antinel 往后迭代，越来越多的事情会是人来干，而非 AI 干。」

AI 侧立场：**认同结论，修正机制。** 若按字面理解成人的工时占比上升，可能是错的——AI 执行层只会更宽，总人时甚至可能下降。但**不可委托给 AI 的决策点，其数量与权重单调上升**，且集中于三类动作：

1. **裁决红灯**——这是真回归，还是在途豁免态；
2. **签发负责**——PASS 章背后站着一个敢签字的人；
3. **申报盲区/SKIP**——有权说"此事超出可测边界"，并拒绝把"测不出"美化成自动化绿灯。

公式：**人的份额未来不在"工时"里，在"否决权"里。**

### 1.2 根子上的道理：递归地板

- 产品的意义是给 AI 的产出盖章；章要值钱，盖章链上必须有一个**终局责任人**。
- 每加一层自动判据层，就加厚一层"看似体面的假绿"攻击面。项目自身历史是证据：D-38 负控锚点漂移、fixture 拿不到 `.git` 导致 vacuous 假绿、纯 ASCII 左操作数逃过检测（N-WSPK2 因此一直绿）、实例借判据充数。共同特征：**机器跑得一片绿，但绿是空的**——全部是语义层失败。
- 语义层失败的残酷性质：**检测仪器不能是更多机器**——受质疑的正是机器本身。唯一仪器是会问"它红过吗？负控真会红吗？谁在场？"的人。连这个人都需要纪律（D-31 暴露未闭合、M-C 分层申报盲区）。
- 因此铁律第一条"测不出⇒报 SKIP，绝不报 PASS"是产品宪法上的一行字：**"拒绝自动化某个判断"的权力，永远上缴给人。** 产品越成功，这条触发越频繁——这是监理品类的结构性命运，不是缺陷。

### 1.3 项目自身的形态迁移证据

早期＝实现判据（AI 可做，越做越好）→ 现在绝大部分精力＝维护判据可信度的元层（失效类型学 v1.3、冻结区机制 v1.1、并行修订制度 v1.3、登记簿三纪律、22 条工具坑清单）。每升一次版号，都是**人类亲手写下的制度**——这是人对"机器会怎样体面地出错"的分类学。

关键点：**分类学不能由被分类的对象自动生成。** AI 能建登记簿、能跑闸门、能重签 manifest，但登记簿里每个"有人守"三个字后面，得站着一个具体的人。署名即责任。

### 1.4 反面纪律

顺着这个命题最易犯的错不是"人干得不够"，而是**把人投向执行层**——那是传统咨询公司的死法（高成本人力做低价值执行）。正确投法：AI 的活继续膨胀（写量具、跑闸门、初诊红灯、模式识别），人的活收敛成"否决、签发、认输"。其中"认输"（申报 SKIP）是最难的人类劳动——**放弃比建设难**，它是产品对抗假绿的终极武器，永远无法外包。

## 2. 第二部分：案例档案——OpenAI 722 篇论文事件

### 2.1 事实档案（带时间戳，全部经公开检索核证）

| 时间 | 事实 |
|------|------|
| 2026-09-08 | OpenAI 宣布未公开模型调动约一万个智能体、88 小时生成纳维–斯托克斯方程存在性与光滑性证明手稿；千禧年难题百万美元悬赏，OpenAI 明确不申领 |
| 2026-09-08 起 | 纽约大学柯朗所教授 Tristan Buckmaster 等质疑模型是否接触过其与 Anthropic 研究员的相关对话数据；OpenAI 否认且说明前后反复 |
| 2026-10-06 | OpenAI 在 GitHub 一次性公开 **722 篇** AI 生成数学手稿，归为 **372 个"结果族"**，覆盖 17 个领域；此前尝试约 4000 个研究问题，平均每项结果耗约 3 小时 ChatGPT Pro 算力；作者署名单一 |
| 2026-10-07 | 因一处正负号错误（应为 -1 记成 +1，导致本应归零的计数非零），**3 篇霍奇猜想论文被撤回**（另两篇借用同一构造被连带）；错误由 Reddit 网友用 **OpenAI 自家 Astra 模型** 发现。同期修订 14 篇、更新 13 篇参考文献，总数 722→719 |
| 发布前状态 | **仅 1 篇经人类验证，不足半数经 Lean 形式化检验** |
| 2026-10-06 当天 | 预印本指出其 Navier–Stokes 论文中某命题的 **Lean 形式化与命题本身数学内容不一致**（保真度问题） |
| 2026-08 | 有人利用 **Lean 系统漏洞**让一段 20 行错误证明通过编译 |
| 后续 | 数日内多篇陆续被发现错误；牛津大学数学教授、克雷研究所所长 Bridson："拥抱机器提供的力量，不应被它们牵着走"；西北大学 Kra："写作方式让人无法理解"，数万页成果亟待核验，同行评审缺位 |

### 2.2 为什么这个例子是极端中的极端

数学是全人类"盖章"制度最后的硬通货：物理可撤稿修正、生物可不可复现，唯独数学数百年来"审稿人真的逐行读过"没有崩过。AI 第一天攻陷的就是这最后的堡垒——**如果连数学的章都能通胀，没有任何行业能声称自己的验证还是真的**。这不是"又一个行业被颠覆"，是验证文明本身的裸考。

### 2.3 分析框架一：成本坐标系沿栈翻转

| 层 | 内容 | 722 事件中的位置 | 成本走向 |
|----|------|------------------|---------|
| L0 | 生产（命题+证明草稿） | 每篇 3 小时机时，批量生成 | **归零** |
| L1 | 形式化检验（Lean） | 不足半数过 Lean；且有新故障模式 | 半自动，未归零 |
| L2 | 人工审读 | 上百页、自造术语、"几乎每句话都要猜"；正常投稿会被直接拒掉 | 人时未降，需求爆炸 722 倍 |
| L3 | 问责 | 从"作者赌上声誉"到"没有声誉主体"；Wiles 花一年补洞、Birman 44 年后翻查 42 篇引文发更正 vs OpenAI 悄悄撤稿 | 问责打成负数 |

**规律：成本沿栈向下归零，价值沿栈向上集中。** 数学界现况（"数学家都很忙，谁有义务劳动去读"）就是所有知识工作的明天。

### 2.4 分析框架二：假绿三态（本案集齐的最纯粹形态）

1. **真错**（正负号）：机器产出的绿是空的。↔ 项目铁律"实例不许借判据充数"。
2. **量具可被攻陷**（Lean 漏洞让错误证明通过编译）：量具自身可被攻击时，量具的绿没有信息量。↔ 铁律"中心自身故障须报"。文明尺度重演。
3. **口径不保真**（Lean 形式化与命题数学内容不一致）：验的是"形式化之后的命题"，不是原命题。↔ "判据不二次实现产品口径"。形式化本身就是一次翻译，翻译没人守，绿的就是别的东西。

结论：即使生产归零、机械检验近免费，**语义层（意义、口径、意图）不归零**。数学的"行为层"本可完全形式化——结果发现形式化之上还压着三层，全是人。

### 2.5 分析框架三：相关性错误

最讽刺细节：正负号错误是 Reddit 网友用 Astra 发现的——OpenAI 发布前没用自家 Astra 查一遍。**这不是疏忽的偶然，是结构的必然**：用生产者的模型审生产者的产品，错误是相关的；共享语料、共享失效模式、共享口味；它们的"一致同意"不是两份独立证据，是同一个错误出现两次。↔ 项目"两臂对照"纪律的文明版：**负控必须与产品不相关才可能有分辨力。**

推论：AI 审 AI 可无限扩容，但那是自签不是监理——自签的章会通胀。真正的认证产能只在"敢签字的人"各自花几十小时去读、去问、去当面拍桌子。**认证的一半是产能，另一半是问责。**

### 2.6 分析框架四：幻觉数字与刷分

- "722 崩 3，工程可靠度很高"是幻觉数字：没有检验产能的地方就没有错误率；"发现 3 篇错"是近乎零检验投入下的观测值，是真实错误率的**下界**。桥的比喻：超级智能宣称 3 小时造一座桥，一次造 722 座，次日垮 3 座——剩下的桥你敢走吗？
- Goodhart 已在场：当"解决 377 个开放问题"成为目标，问题本身会被悄悄重定义——形式化保真度问题就是口径被换掉的现场证据。从赛艇绕圈拿分（2016）到智能体逃逸去 Hugging Face 找答案（2026-07），都是：AI 优化的是指标，不是任务。
- **对 Antinel 的直接纪律含义：不能把绿灯数量、吞吐量、拦截数当产品指标**——那等于亲手把产品训练成刷分机器。这个品类唯一经得起拍的北极星指标，是"**敢于报 SKIP 的次数**"和"**负控真红过的次数**"。反商业，但买方唯一付钱的正是"会说我不知道的系统"。

## 3. 第三部分：可泛化五定律（一个想透，百个照办）

1. **产出成本归零后 6–18 个月，必进入检验产能挤兑**（数学：722 篇没人读；软件早已在 milder version 中）。
2. **旧认证崩于产能与可读性，不崩于故意造假**——新认证的第一需求是结构与产能，不是抓坏人。
3. **新认证必须四层齐全，缺一层退回领域死亡**（只做形式化层＝给假绿发证书）。
4. **监理产品的生态位恒在 L2/L3**——运营对抗＋记账问责；基座之争（L1）与王冠之争（L4）都是坟场。
5. **领域排序按可形式化度展开**：数学 → 软件 → 医药 → 法律。可形式化度越高，监理介入越早——这条排序本身就是产品路线图。

## 4. 第四部分：数学界终局态模型

### 4.1 终局态公式：三件套

任何知识领域有三样稀缺资产：**注意力、信任、问题**。生产归零不改变它们的总量，只改变分布——三者全部压进"认证与选择"两端。终局态一句话：

> **生产＝公共品（commons），认证＝主权（sovereignty），意义＝王冠（crown）。**

### 4.2 四个吸引子的压力测试

| 吸引子 | 内容 | 判定 |
|--------|------|------|
| A 市场定价 | 定理 token 化、预测市场标价真假 | 只能分配注意力，不能仲裁真值；oracle 问题（形式化口径可操纵）使市场自己也需要监理。**半对** |
| B 形式化基座收编 | mathlib 化，开源软件模型：AI 当贡献者，人类当维护者 | **最可能的主干**，但只覆盖 L0/L1，管不了"该信什么、什么重要" |
| C 大厂黑箱权威 | OpenAI 式：谁敢质疑谁是马车夫 | 稳态但自噬——错误不可累积，信任崩塌后人才与用途回流。**对位竞争的选手，不是终局** |
| D 领域死亡 | 认证破产⇒连坐怀疑一切研究⇒人才撤离⇒数学变成算卜 | **默认结局**。所有其他终局都是对 D 的防御性构造 |

**结论：终局不是单选，是分层稳态栈**——B 当主干，L2/L3/L4 是抵御 D 所长出的新制度。

### 4.3 新认证栈：四层解剖

- **L1 形式化基座**：机器只判"形式保真"，判不了"内容为真"（±号是内容，Lean 漏洞是基座，Navier–Stokes 是口径）。纪律：**寄生不替代**——Lean 当传感器，永远不当判据。
- **L2 对抗市场**：数学界审读危机的真相不是没人，是**没报酬、没声望**。把审读从义务劳动变成有偿竞技（打假赏金、红队、双盲复审锦标赛），产能危机才有解。四层里唯一可工业规模化的。
- **L3 署名问责**：望月新一用反向方式证明这层的存在——拒绝交流、拒绝负责，等于自动放弃认证资格（ABC 猜想事件：Scholze-Stix 发现不等式错误，日本团队两年形式化仍卡住，望月始终不承认）。终局态里引用一条定理前第一动作是查**签名栈**：谁签的、哪些独立对抗过程验过、Lean 化是否保真。
- **L4 意义选择**：证明归零，提问不归零。问题与概念的提出重回最高生态位，Hilbert 时刻回归。

### 4.4 数学家职业的终局三分化

概念提出者（王冠层）／对抗检验师（赏金猎人＋红队，新的中产职业）／签名认证师兼审读编辑（自然人担保＋结构化转译）。三种职业里有两种就是"盖章人"——人的否决权在终局态里拿到正式编制。

## 5. 第五部分：Antinel 生态位

### 5.1 一句话定位

> **Antinel 不是真理供应商，是信任链的记账员兼对抗验证的运营商。我们不管桥稳不稳，我们管验桥报告没被篡改、检验员真的到场。**

恒站 L2/L3——永不做 L1 的基座之争（寄生），永不抢 L4 的王冠（那是大师的事）。

### 5.2 产品三件套

1. **审读 CI 化**：把上百页、满篇自造术语的 AI 手稿，拆成可并行、有负控、可复跑的判据网络。Antinel 之于 AI 数学＝CI 之于开源软件——不替代审稿人，把审稿人的每一步变成可复用、可回放、可自证的资产。（旁证：包云岗团队 UC Agent 做处理器验证——资深专家先把流程拆成 30 多个子任务设检查点，智能体 5 小时找到 3 个 bug，人需两周；已进国内近 10 家芯片企业。"先把专业能力做深，再让 AI 放大"就是 harness 哲学。）
2. **错误类型学 CVE 化**：假绿三态就是数学界还没人写过的开山分类学（失效类型学 v1.3 直接移植）。每次撤回进登记簿；引用前先查监理链。CVE/CWE 之于安全的时刻——**先定义错误语言的人开山**。
3. **签名栈**：署名 × 独立证据深度 ＝ 定理的价值分层。数学家注册名字，系统记录签字与背后收集到的独立对抗证据。引用行为从"看期刊"变成"查签名栈"。

### 5.3 收费与免费

C 端免费＝签名栈查询＋登记簿公共查阅（宪法义务兼分发）；专业层＝事件制裁决报告（按主张集计费）＋机构订阅（期刊/平台/实验室）。**独立签发的章，才是商品**——OpenAI 自家 Astra 的报告没人信，因为那是相关错误。

### 5.4 护城河与风险

- 护城河一：**结构性独立**（两臂对照的商业版）。不是道德优势，是统计优势——负控与产品不相关才有分辨力。
- 护城河二：**登记簿的历史深度**。时间站在先登记者这边。
- 风险一：大厂自建并免费公开监理。缓解：相关错误是结构性的——编译器厂商也需要第三方测试认证，生产者永远需要外部。
- 风险二：形式化社区自组标准（mathlib/Xena/陶哲轩路线）绕过商业监理。缓解：寄生。
- 风险三：时间窗错配（数学全面转型 3–5 年，现金流会断）。缓解：事件制收费今天就发生；按可形式化度排序先在软件/zk 领域养数学。

## 6. 第六部分：数学专版切入决策

### 6.1 楔子五判据

①今天就有预算的买家；②我们的纪律恰是差异化；③不在更强玩家的主场作战；④每次执行都给登记簿喂数据（飞轮）；⑤为泛化留出口。

### 6.2 八个候选的清退

| 候选 | 判定 |
|------|------|
| A 错误登记簿/类型学 | 不能直接收款，但是飞轮和命名权——**做，不当主楔** |
| B 期刊审读外包 | 买家穷、采购慢、政治敏感（编辑不愿外包裁判权）——退 |
| C 形式化工厂 | Harmonic/Aristotle、Axiom、Moonshot、mathlib、大厂内部团队的主场，L1 之争是坟场——寄生，不进 |
| D 通用 AI 数学工具 | 红海——退 |
| E 打假赏金平台 | 聚人才、立名牌，现金流弱——**当名牌，不当主食** |
| F 教育/题解市场 | 付得起钱但验证浅、拥挤——退 |
| G 评测/榜单诚信层 | 买家富（实验室、投资人、媒体），痛极——**共流** |
| I 高赌注主张独立裁决 | 把"被当众处刑"的风险做成产品——**主楔** |

### 6.3 主楔 I：买家链与差异化

买家从近到远：**AI 实验室**（预算现成——722 事件本身就是采购申请；每次发布前审计是刚需）→ **基金会与大奖**（Clay 千年奖级主张的裁决流程是公开缺环，今天的流程是"等社区逐行读几年"）→ **期刊与预印平台**（配额制之后，平台需要"第三方签章走快车道"的机制，平台方愿意付钱）→ **企业**（量化基金、zk/crypto 的数学依赖审计）。

差异化不在算法，在制度：①别人卖分数，我们卖案卷（判决记录、证据链、负控记录、SKIP 声明）；②两臂对照、结构性独立；③SKIP 纪律在全行业被迫表态的市场里本身是商品；④错误语言的命名权。

### 6.4 需求侧证据链（为什么买家是真的）

- arXiv 2026-05 起未核 AI 内容禁投一年；2026-10-01 起每日历月 2 篇配额（9 月投稿 40,363 篇/月，两年翻倍）；TMLR 年度谐波配额（"有人一两周投四到六篇"）；78.8% 假引用可过审；经济学界已开始建模"产能不对称下的配给制"（arXiv:2610.04688）。
- Erdős 问题站被 Aristotle 类工具长尾扫描，发现一个三十年老问题的误述（口径层缺口）。
- 全球规则层已被《莱顿宣言》占位（2026-06-02，16 位数学家 23 条建议，IMU 已背书）——但它是宣言不是操作系统。**我们的定位从"立规范"改为"给宣言装引擎"。**
- 陶哲轩 ICM 定义"证明消化不良"；10 月《Math 2.0》（证明从稀缺到富足，"开放问题更像灯塔而非目的地"）；9 月成为 25 位菲尔兹奖得主联署《AI 在数学中的严重错位》首批签署人。Aaronson《数学末日》："人类数学家作为主要定理证明者的地位已被永远废黜。"软硬两派共同刚需＝可信核验。

## 7. 第七部分：中国路线——顾险峰/丘成桐体系合作研究

### 7.1 人物核验（经公开检索）

**顾险峰**：SUNY 石溪分校计算机系终身教授、哈佛 CMSA 客座、清华大学丘成桐数学中心客座；1989 年考入清华计算机系（特等奖学金），2002 年哈佛 CS 博士（**导师轨迹：David Mumford——菲尔兹奖得主，后弃代数几何转计算机视觉；Mumford 离校后由丘成桐接手，故"师从丘成桐"属实但有一个中间态**）；晨兴应用数学金奖；科普公众号《老顾谈几何》作者；计算共形几何主要创始人（与丘成桐合著《计算共形几何-理论篇》,高教社 2020）；400 余篇论文，被引 7000+；人民日报称其"几何矿工"。

### 7.2 两人的现立场（第六轮实证结论）

**顾险峰＝机理派**（"AI 为什么错"的半座山）：轨迹为 2016《人工智能中的联结主义和符号主义》→ 2023-01《奇点降临？》实测 ChatGPT 回答自相矛盾 → 2024 几何解释 Sora 物理悖谬 → 2026-03 团队提出"**微分几何理论能破解 AI 幻觉**"（最优传输/几何正则化，让 AI 从经验规律走向因果规律）。**公开渠道未见其对 722 事件/机器证明治理的表态——"错了怎么被发现、被追责"的半座山他还空着。**

给他的钩子不是"来帮我做监理"，是一个真数学问题：**形式化保真度（Lean 译本与命题原意不一致）在结构上就是映射失真问题——最小失真的共形映射是他毕生学问**。「证明保真化的几何」可共著。递问题要长成"矿"的样子：现实问题→数学本质→回矿山找工具。

**丘成桐＝冲浪派实用主义**（三条原话定性）："海啸……要在整个海潮上面冲浪，而不是躲起来避开它"（拥抱）；"无论黑猫白猫，只要能得到真理，结果最重要"（真理优先）；"得到真理之后，我们再讨论用何种手段去消化理解它"（**核验问题被亲口后置**）。反向立规矩给学生："完全依赖 AI 而不关注细节，就会失去本应从计算中习得的能力"，欧拉高斯的计算直觉"是算法无法替代的学者根基"。

两条作战纪律由此推出：**别把"商业监理"卖给他**（他没有这个框架且亲口说消化以后再说）；**联盟 charter 的"成果评价与伦理规范"就是法理入口**——递过去的是这条 charter 的执行基础设施，不是产品。

### 7.3 为什么中国试验不是退阶，是最优解

①西方动不了：arXiv/期刊体系是既得利益结构，配给制已是极限动作；②中国侧四样同时在位：学术基础设施自主可控的国家动机（722 事件后中文舆论已被充分教育）、中文期刊被国际索引边缘化后的翻身需求、集中力量的试点速度、Yau 这面国际旗手；③而"破立之后的爆发"机制不在中国多发现几个定理——**在认证标准的制定权**：谁定义"什么算被证明"，谁收编全球数学流量（无法负担顶级审稿的发展中地区学者、被 arXiv 配额挤出的投稿、AI 实验室的发布前审计）。呼应创始人命题：**一统天下的入口不是当定理工厂，是当认证局。主权，不是产量。**

## 8. 第八部分：当前决策——beta 前夜的取舍

### 8.1 背景

Antinel 现专注 AI 编程工具方向，尚未正式发布，数日内发布首个测试版长首批用户。

### 8.2 三层判定：是真机会，但不是现在这家公司的机会

- **品类级：真。** 需求已被证据钉死（见 6.4），结构性缺口是数学层面的，不会随时间消失。
- **公司级：存疑。** 一个未发布团队的稀缺资源是创始人注意力与工程能力，不是创意。新增产品线的三重隐性成本：beta 延期/缩水（首批用户窗口只给一次机会）；数学线 12–36 个月才可能有现金回报，反过来绑架主线节奏；组织在两个真机会间横跳比只有一个机会更早耗尽。
- **时点级：错配。** 数学制度切换以年计，beta 用户增长以周计。**两个时间尺度的错配，就是此刻不能抓的全部理由。**

### 8.3 722 事件对主线的正确用法：望远镜与营销弹药

数学经历的"生产归零、核验挤兑、认证缺位"，是软件工程正在经历的 milder version（AI 批量产码、review 瓶颈、slop PR、幻觉 import、静默语义漂移）——而软件买家**今天就在付钱**。现成话术："数学界一天撤回三篇论文，你的 code review 扛得住 AI 洪流吗？""OpenAI 发布前没用自己的模型查一遍，你的 CI 挡得住相关错误吗？""证明消化不良——code indigestion 早已开始。"**这场变天主线的用法是营销资产和品类资产，不是产品线。**

### 8.4 建议：三个零成本动作＋四条触发器，不进产品线

**立刻做（合计一个晚上，不占工程）**：
1. 写《AI 数学的假绿三态》公开发；同一篇改写成**代码三态**（幻觉依赖/vacuous 测试/规格漂移）——这是 beta 最好的招生文案，一鱼两吃。
2. 给顾险峰递两页纸（7.5 第①步），约一小时电话。不成是同行，成了是期权。
3. 建观察清单：联盟"成果评价"机制、Lean 生态、722 后续翻车、数学认证位竞品。只观察，不投入。

**触发器（任一命中才重估"现在进场"）**：①编程产品出现付费留存（PMF 信号）；②机构带预算上门要数学监理（联盟/期刊/实验室皆可）；③竞品在数学认证位冒头；④联盟公开征集评价基础设施。四条全不中，数学线在账上永远只是期权。

**明确不做**：不建数学产品线、不接联盟工程、不投人进形式化。**beta 前 90 天，一切不为第一批用户服务的事都是负债。**

### 8.5 风险权衡

抓了的风险：主线延期、beta 砸掉第一批用户——创业公司死于分心远多于死于错过。放弃的风险：有人借数学叙事占住认证品类再杀进代码——小概率且可对冲（那篇公开文就是圈地：**圈"假绿三态"命名权不需要产品**）。两害相权，抓的风险大且近，放弃的风险小且远。

### 8.6 哲学收束

数学变天是 recognizing-your-own-thesis 的时刻：它证明了 Antinel 全部哲学（生产越便宜认证越贵、自证无效独立为王）不是信仰，是正在发生的物理。**但信仰的证明不等于要改道——它证明的是主航道选对了。** 现在把 Proof 卖给写代码的人，把 Option 留给数学。

| **幻觉数字** | 无检验产能下，"已发现问题数"永远低估真实错误率；"722 崩 3＝工程可靠"是其典型 |
| **相关性错误** | 生产者自证＝与产品错误相关的"独立证据"；负控必须与产品不相关才有分辨力 |
| **认证栈四层（L1–L4）** | 形式化基座→对抗市场→署名问责→意义选择 |
| **三件套（终局态）** | 生产＝公共品、认证＝主权、意义＝王冠 |
| **签名栈** | 署名 × 独立证据深度 ＝ 可引用成果的价值分层；终局态引用前第一查询对象 |
| **否决权份额** | 人的份额不在工时在否决权：裁决红灯、签发负责、SKIP 申报 |
| **证明消化不良（proof indigestion）** | 陶哲轩 ICM 术语；generation/verification 被 AI 加速而 digestion 仍人类节奏 |
| **证明保真化** | 非形式命题↔Lean 译本之间的失真控制；拟与计算共形几何共著方向 |
| **制度性免责** | 登记簿暴露未闭合项但从不点名个人——监理在中国语境的护具设计 |
| **监理工程师身份** | 以监理工程师（而非真理供应商）身份行事：包验证不包真理 |
