## 0. 一句话主张

**每个页面只回答一个问题，每个事实只有一个家，每个数字只有一个算法；
人和 Agent 读同一份底座，只是渲染不同。**
跨页需要同一事实时，用深链，不复制品。

## 2. 页数推演：为什么是五页

**页的立案标准**：一个高频用户问题 ＋ 独立时间窗 ＋ 独立行动集，三者齐备才配一个页。

| 候选问题 | 频率 | 行动集 | 判决 |
|---|---|---|---|
| a. 我有没有中招？谁在偷数据？ | 首次＋每周/月 | 重跑、看裁决、布金丝雀、导出一页纸 | ✅ **独立页（体检）**——独立旅程、独立时间结构（时点快照） |
| b. 现在有什么要我处理？ | 最高 | 知道了/忽略/放行裁决 | ✅ 收件箱 |
| c. 今天/昨天怎么样？ | 每日 | 钻取、导出一页纸 | ✅ 日报 |
| d. 之前每天都发生了什么？ | 低（取证） | 按天/按月翻、认领 | ✅ 账本 |
| e. 监理自己靠谱吗？ | 低（出事时） | 复核、重拉 | ✅ 运行状态 |
| f. 花了多少钱？还能站多久？ | 中 | 设预算、记账 | ❌ 不立案：事件（预算告警）进收件箱，余量进运行状态，明细走 CLI——"钱"与"安全"同属自省，拆页割裂 |
| g. 给领导交差 | 低 | 导出 | ❌ 产出物不是页：日报/体检的"导出一页纸"按钮 |
| h. 跨工具汇总 | 中 | 筛选 | ❌ 日报排行的工具分布即页面版 |

**否决"粮草独立页"的理由（E198 纪律）**：粮草账（积分/元）与审计账（条/次/件）**异质单位**，
绝不能混进账本；而它的高频行动（设预算）已有 CLI 与事件通道，页级行动集不足。

**五页 = 体检、收件箱、日报、账本、运行状态。** 页序即旅程序（首次用户第一眼是体检）。

## 3. 双受众界面原则（为人服务，也为 Agent 服务）

Agent 不读网页；网页不给 Agent 看。但双方必须读**同一份事实底座**：

| 原则 | 内容 | 现状 |
|---|---|---|
| ① 同一底座、两种渲染 | 页面渲染给人；`--json`／MCP 渲染给 Agent。共用 glossary／规则表／宿主表真源，不许第三份实现 | glossary 已是唯一真源 ✅ |
| ② CLI 人话＝Agent 转述底稿 | Agent 替人跑命令后**转述**给人——所以 CLI 文案与页面同一套用词、同一套人话纪律；`--help` 的 Agent 话术表就是用户话术表 | 已具雏形，随 §5 机制统一 |
| ③ 页面能说的，命令都能给 | 可验证性的机器侧：每个页面事实都有 CLI/JSON 出口（反 packed：命令能给的页面都该能看） | host-scan --json 等已有；补缺口 |
| ④ 被监理的 Agent 也是用户 | 钩子拒绝消息是 Agent 的"界面"：必须人话＋可行动（"改用 xx 路径／见规则 DST-04 的大白话"） | post_tool_use 已人话化，纳入同一套判据 |
| ⑤ SKILL.md 是 Agent 的"首页" | Agent 的装机说明书；与控制台同一套术语真源 | 已随包 ✅ |

## 4. 五页逐页规格

### 4.0 体检（新增，第一位）

**回答**："这台电脑和这些 AI 工具，现在什么状况？"

三段结构（全部只读；`--arm` 布防是显式动作）：
1. **装机盘点**：host-scan 全工具清单＋六档裁决（自认打包过／自认往外发过／自认在同步／查过没发现／没查到／不适用）——**盲区单列，不冒充清白**。
2. **外传与布防**：egress 审计摘要＋金丝雀状态（布了几个、哪个被读过）。
3. **历次对比**：本次 vs 上次体检——"新装 1 个工具、新增自认外传 2 条、新增 1 个未裁决落点"。

旅程与节奏：
- 首次：装前体检（零风险只读）→ 决定装 → 装后复检（页面上能看到"监理在岗"）。
- 复查：每周/每月；**超 N 天未体检 ⇒ 收件箱出提醒事件**（提醒的独占家在收件箱，体检页只显示"上次体检 X 天前"）。
- 报告留存：历次体检结果可回看（时点快照，不进账本——流水与快照异构）；可导出一页纸。

实现注：复用 `ui_server` 现有渲染与 `VERDICTS` 六档（唯一实现，不许重写第二份六档）；
控制台 TAB 与其合并或内嵌，实现方式执行期定，IA 以本节为准。

### 4.1 收件箱
1. 撤顶部 24h 计数排（家在日报四数）。
2. 第二行去重：时间只在行首；不复述标题状态；≤90 字。
3. 工具徽标（**≥2 工具才显示**）＋展开区证据句（无环境变量名）。
4. 归并行分布；`host:` 过滤器（`filter_items` 第 7 前缀）。
5. 预算/体检提醒事件在此进出。

### 4.2 日报
1. 窗口统一"今天（本地自然日）"，删"当日＝24 小时窗口"混用（代码注释 `:1889` 自认）。
2. 四指标保留（本页本职）。
3. 规则命中排行行尾加工具分布（不新增小节——另开一节＝同页两套计数）。
4. 口径说明合并为一句；"导出一页纸（brief）"入口。

### 4.3 账本
1. 撤头部四指标卡（家在日报）；区一起点改"昨天"（今天的账看日报，一行深链）。
2. 按月折叠不动。

### 4.4 运行状态
1. 撤业务计数；新增"工具识别"块（判定方式／最近 7 天成功数／说不清占比 >5% 提醒／旧记录分代）。
2. 新增"粮草"小块：余额、燃烧速度、按当前速度还能站几天、未结预算告警数——**只显示，不记账**（账在 CLI）。
3. "未能核验"升级为明确告警："这次没核验成：0 个文件被检查——结果不算数"。
4. 证据链核验入口（verify 深链）。

### 4.5 跨页时间窗总表

| 窗口 | 家 | 别页 |
|---|---|---|
| 滚动 24 小时 | 收件箱 | 禁入 |
| 今天（自然日） | 日报 | 账本区一从昨天起 |
| 最近 7 天 | 运行状态（工具识别健康） | 与账本区一同锚（一周） |
| 时点快照 | 体检 | 不进账本 |
| 全历史 | 账本 | — |

## 5. 三层机制（先立尺子，再改产品）

### 5.1 机制一 · 同一事实单一出口
- 事实→家映射固定：状态词→顶部条；事由名→标题；为什么→第二行；怎么办→展开区；
  工具→徽标；计数→其独占页（§4.5）。
- 机器检查：**句子指纹**（去数字标点后 ≥8 字片段同页出现两次即红）＋**数字唯一**
  （同值同口径只渲染一次；同值不同口径必须各带限定词）。
- 负控：故意在第二行复述时间 ⇒ 必红（现网活体：L2 条目行首与第二行各写一次时间）。

### 5.2 机制二 · 正确性
1. 数据保真：链→Alert 字段不丢（实锤：链上 107,955 条带 host，Alert 层全丢且无人守）。
2. 口径唯一：工具维度扩进 `M.day_counts`，渲染层禁自算。
3. 声明可验证：页面上的规则号必须存在于规则表、工具名存在于宿主表、数字能追到结构化数据。
4. 失败要说出来：核验没跑成 ≠ 通过。

### 5.3 机制三 · 品质性
1. 鸟语黑名单：环境变量名、内部实现词（口径/归并/徽标/宿主/投影）、无解释英文缩写；
   白名单：规则编号（创始人 2026-10-17"规则编号肯定也保留"）。
2. 长度：条目第二行 ≤90 字（实测现 100+）；单句 ≤40 字。
3. 指代显式（F57）；同屏重复率。
- 全部判据化并入既有套件（A2 常驻 29 已满）：渲染类→0490，文案类→0360 W 族，数据类→0353。

## 6. 工具归因（原点需求，数据事实不变）

- 552 个登记项目根、129,058 条工具调用记录：83.6% 带 host；16.4% 为 0.33.1 前旧记录；
  qoder 9,085 条＝目录标记劫持残留；近 8 天 100% workbuddy。
- `Alert` 加 `host`＋`host_confidence`；`inbox_store` 三个转换点补读；链格式零改动（AUDIT_SCHEMA 不升版）。
- 徽标四态：工具名（env 铁证）／可能是 X（目录标记，展开区给依据）／来源不明／旧记录。
- 归并行与日报排行显示分布；归并键不变（"条目要少"是 2026-10-06 拍板）。
- 边界：R0 篡改不可指认工具（只显示"系统自检发现"；同期写入只作「推断」）；
  措辞纪律：工具是"来源"不是"责任者"，不用"造成"。
- 宿主人话名：25 个 `rules/hosts/*.json` 加 `name`（核实官方命名，核实不了先显示原标签）；
  判据：检测器标签表 ⊆ 宿主表且都有 name。
