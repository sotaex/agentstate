## 2. 三条判据 + 一条行为半边（全部机械化）

### JDG-01 状态路径一致性：测试重置路径 == 产品读取路径

- 产品路径：AST 取出 `notice_state_path()` 函数体（去 docstring），在受控命名空间执行，取真值——**不重写路径逻辑**。
- 测试路径：AST 找出所有重置 `notify_state.json` 的赋值语句，在镜像命名空间（同一 `ANTINEL_HUB_DIR`）里求值。
- 判据：至少一处重置路径与产品路径**逐字节相等**。
- 第一用例即 UX：修复前重置 `.psl/` 死路径；修复后改为 `Path(os.environ["ANTINEL_HUB_DIR"]) / "notify_state.json"`（与产品同一口径，env 由套件第 71 行指进沙箱）。
- **行为验证**：修复后原样复现 UX 断言 ⇒ PASS（首条提醒出现、同类第二次静默）。

### JDG-02 通道一致性 I4：每条气泡路径都过可见性闸

AST 限定名调用图（`文件:函数`），三个机制：

1. **发射者闭包**：沿 `resolved` 传递，能走到真身（`ShowBalloonTip` 常量）或原语的函数都算发射者。
2. **入口 = 源 SCC**：调用图上游无外部流入的强连通分量（自递归的 `main`、相互递归的环都算入口）。
3. **有效闸**：函数调了 `console_is_visible`（或 `force=True`）**且本层直接触发发射**——闸长在无关代码上不算数。

实测：21 个发射者 / 4 个入口。第 7 例（notify 无闸）修好后全绿。

### JDG-02B 通道行为：真实通道弹/不弹四象限（结构之外的第二个半边）

- 为什么必须有：结构检查是**语法层**的。实测把闸写成 `if False and console_is_visible()`——调用还在、结构绿、行为已死。
- 做法：副作用隔离（临时 `ANTINEL_HUB_DIR`）后，`reload` 产品模块，在**效应边界**测量：
  - `host_shield.notify`：可见 ⇒ 不调 `_notify`；不可见 ⇒ 调。
  - `hooks/pre_tool_use.notify_owner`：可见 ⇒ 不起 `Popen`；不可见 ⇒ 起。
- 四象限全对才算过。

### JDG-03 清单归属分账：不符必须可归属

- 相符 ⇒ ok；不符 + git 在管 ⇒ **WIP 陈旧**（合法编辑，清单没跟上）；不符 + 未入 git / 文件缺失 ⇒ **真漂移**（红）。
- 本版修正了「HEAD 比对」的误报：harness 快照之后的编辑会同时不符 digests 与不符 HEAD，第一版据此误判真漂移。
- 现状实测：19 相符 / 2 项 WIP 陈旧（`host_shield.py`、`pre_tool_use.py` 的 0.36.7–0.36.8 编辑），0 真漂移。

## 3. 量具自审记录（本文件最该被读的部分）

JDG 族第一版有 **6 个自身缺陷**，全部被实跑/负控当场抓出。逐条记账：

| # | 缺陷 | 怎么发现的 | 修法 |
|---|---|---|---|
| 1 | `return` 无家可归：去 docstring 后把函数体平铺成模块语句 | 首跑 SyntaxError | 保留 FunctionDef，只换 body |
| 2 | `direct` 用常量**全等**比对 `ShowBalloonTip`，真身是长 PS 串的一段 ⇒ 所有路径空转 `all([])` 成 True（**假绿**：放过了未受闸的 notify） | 负控造不出红 | 改子串匹配 |
| 3 | 调用图用**裸函数名**做 key ⇒ 跨文件同名合并，一个文件的 gated 掩盖另一个的未受闸 | 入口只有 1 个，cli 树隐形 | 限定名 `文件:函数` |
| 4 | 发射者只算**一层** ⇒ `_roots_add → seven_step → notify` 整链不在集合内 | 入口可见性异常 | 传递闭包 |
| 5 | 入口 = 「无仓内调用者」漏掉自递归的 `main` ⇒ CLI 树全盲 | 牙齿检验 A 失败 | 源 SCC 定义 |
| 6 | docstring 也算常量 ⇒ `console_is_visible` 的说明文字提到 `ShowBalloonTip` 被误判为发射者 | 红项点名 console_is_visible | 扫常量跳过所有 docstring 节点 |
| 7 | 行为半边复用**已导入模块**，负控改磁盘不 reload ⇒ 测的是旧字节 | 负控 False | 行为相位先 reload |
| 8 | 闸的检测是语法层 ⇒ `if False and console_is_visible()` 洗白 | 牙齿检验 A 漏报 | 增加 JDG-02B 行为半边 |

**共同教训（值得上升为纪律）**：

> 检查条件写了，不等于它检得到那个东西。判据必须能在**效应边界**上被证伪——
> 负控不是形式，是判据的牙齿；没有负控的判据只是一段会执行的代码。
