## 三、`audit_chain.py` 不是「零删除/轮转」—— 有 3 处覆盖写

方案书 §3.3 第 7 段原文：「**零**：`audit_chain.py` 无任何删除/轮转逻辑」。
AST 实测（探针有牙：正控 `os.remove`＋`shutil.rmtree` 命中 2 处，负控纯读样本 0 命中）
查得 **3 处 `os.replace(...)`**，逐处判定如下：

| 行 | 代码 | 性质 | 判定 |
|---|---|---|---|
| **L102** | `os.replace(p, p + ".1")` | `lock_events.jsonl` 超上限时只留一代 | ✅ **有界轮转**，目标不是审计记录 |
| **L304** | `os.replace(path, path + ".away")` | 死锁残骸改名让开（D 盘禁 unlink 的唯一出路） | ✅ **改名**，不是删除 |
| **L593** | `os.replace(tmp, mpath)` 覆盖 `day_manifest.json` | 日锚回写 | ⚠️ **有真实风险，见下** |

### L593 的风险是结构性的

```python
try:
    with open(mpath) as f:
        man = json.load(f)
    if not isinstance(man, dict):
        man = {}
except Exception:
    man = {}          # ← 读失败 ⇒ 整份历史锚被当成空
prev = man.get(day) or {}
if size >= int(prev.get("size", 0)):
    man[day] = {...}
    os.replace(tmp, mpath)   # ← 用「只有今天这一条」覆盖整份清单
```

**读失败（文件损坏、并发读、被占用）⇒ `man` 塌成 `{}` ⇒ 回写后整份 `day_manifest.json`
只剩当天一条，其余天的锚无声消失，且外层 `except Exception: pass` 不报错。**

后果链：**日锚是 `verify_chain` 判定整数性删除的唯一依据** ⇒ 锚被清空后，
历史日的尾部删除检不出来。这不是「防不住主动攻击」，是「一次读失败就自毁证据」。

**为什么不本轮修**：0.63.2 的补丁额度已用满 **3/3**（`publish_hold.review_log` 第 3 次复核），
冻结期补丁线只接「拦截集合单调不增」的修复。本条属记账完整性，**修法需单独排期**：
最小形状是把 `man = {}` 改成「读失败 ⇒ 不写回 + 留一条可见的降级记录」（失败要不写，不是写个空的）。

## 五、日锚覆盖（B-8）：31/33 天有锚，2 天检不出

方案书 §7.2 步 1 要求「每日 `(day, size, last_hash)` 写进**用户可见的报告**」。
`day_manifest.json` 里这三个数一直在，但**没有面向用户的出口**。补上出口后先看到的是覆盖面：

| 项 | 读数（2026-10-31 21:44） |
|---|---|
| 日文件 | 33 个 |
| 锚条目 | **31 条**（最早 2026-09-26 → 最晚 2026-10-31） |
| 判定 `OK` | **31 天** |
| 判定 `无锚` | **2 天**：**2026-09-25**（锚起点之前）、**2026-10-05** |

**2026-10-05 值得单独看**：它不是空洞日（空洞是 09-30/10-01/10-02/10-04），
文件在、442 条记录在，却没被锚覆盖 ⇒ 那一天的**尾部截断与整文件重写今天检不出来**。
锚是在「写记录时」顺带更新的，非当日写入的日文件不会补锚。

判定规则的三条腿（同一把尺子，`classify()` 纯函数注入）：

| 腿 | 内容 | 结果 |
|---|---|---|
| 负控 | 原样不动 | ✅ `OK` |
| 正控 1 | **同长度改内容**（把末行 hash 改掉、字节数不变） | ✅ `REWRITE` |
| 正控 2 | 截短（摘掉最后一行） | ✅ `SHORT` |

`REWRITE` 必须单列：**同长度不同内容**是哈希链与 size 都抓不到的形态，
也是锚唯一能抓到重写的场景 —— 把它并进「其他」就等于放弃锚的一半价值。

**限定语（必须随页一起给用户，不许省）**：锚与日文件**同目录同权限**，
能改日文件的人也能改锚 ⇒ 这一页证明的是「与登记值自洽」，**不是**「没被人动过」。
