## 修了什么

1. 「最早的一条已经 0 天没管」→「今天搁下的」。
   当天搁下的条目一定显示「0 天没管」，而「0 天」不是存在的时间长度，
   读起来还与"刚搁下"方向相反。结构属性 data-ack-days 一个字节未动。

2. main 上补回 serve 的 --ensure / --log。
   计划任务的动作是 `serve --ensure --log …`，而 main 的 cmd_serve 既没注册
   这两个参数、也没有幂等分支 ⇒ argparse 直接报 unrecognized 并以退出码 2 结束，
   日志里一行都没有（argparse 在写日志之前就退出）。
   实测 Get-ScheduledTaskInfo：RESULT=2 → 现在能走到幂等分支。
